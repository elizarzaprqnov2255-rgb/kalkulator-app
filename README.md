# Калкулатор – електромонтажни услуги (офлайн)

Файлове: index.html, manifest.webmanifest, sw.js, 3 иконки.

## Публикуване в GitHub Pages (безплатно)
1. github.com → New repository (напр. `elektro-kalkulator`), Public.
2. Add file → Upload files → качете ВСИЧКИ файлове от архива (разархивирани, не самия архив) → Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка /(root) → Save.
4. След 1–2 минути адресът е https://ВАШЕТО-ИМЕ.github.io/elektro-kalkulator/

## Инсталиране на iPhone/iPad
1. Отворете адреса в Safari (при връзка с интернет, само първия път).
2. Бутон „Сподели" → „Добави към начален екран".
3. Стартирайте от иконата – работи без интернет.

## Обновяване на цените
Сменете файловете в хранилището и увеличете версията в sw.js (`elektro-v1` → `elektro-v2`).
