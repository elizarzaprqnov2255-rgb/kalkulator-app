# Калкулатор – електромонтажни услуги (офлайн, iPhone)

Файлове: index.html, manifest.webmanifest, sw.js, 3 иконки.

## Публикуване в GitHub Pages (безплатно)
1. github.com -> New repository (напр. `elektro-kalkulator`), Public.
2. Add file -> Upload files -> качете ВСИЧКИ файлове от архива (разархивирани, не самия ZIP) -> Commit.
3. Settings -> Pages -> Deploy from a branch -> Branch: main, папка /(root) -> Save.
4. След 1–2 минути адресът е https://ВАШЕТО-ИМЕ.github.io/elektro-kalkulator/

## Инсталиране на iPhone/iPad
1. Отворете адреса в Safari (с интернет, само първия път).
2. Бутон „Сподели“ -> „Добави към начален екран“.
3. Стартирайте от иконата – работи без интернет.

## Настройки
Бутон със зъбно колело -> ПИН 3890 -> цени на всички позиции.

## Обновяване
Сменете файловете в хранилището. Новата версия се показва при второто отваряне на приложението.

## AI асистент
Текстът работи офлайн. Гласът, снимките и таблиците искат интернет и API ключ (Настройки -> AI асистент). Офлайн диктувайте с микрофона на клавиатурата.
